\section*{全体概要}
\subsection*{システムの概要}
LINE から設定できる照明,メッセージによる目覚まし時計
\subsection*{製品の機能}
目覚まし機能は照明と,Lineに届くメッセージにより行われる.LINEから スヌーズ機能, 曜日ご
との設定, 日ごとの設定, アラームの解除ができる. 照明はその日の天気が分かるよう晴れなら冷色, 雨なら暖
色, 曇りならその中間の色の明かりがつく.
\subsection*{想定する利用者の特性}
明かりの要素がある目覚まし機能であり, その調整をスマホで遠隔で行えるため, 目覚まし機能を求める人を
想定している.

\section*{詳細}
\subsection*{機能要求}
\begin{itemize}
    \item ユーザは LINE から目覚ましの機能 (スヌーズ機能, 曜日ごとの設定, 日ごとの設定, アラームの解除) が設定できること.\\
    \item 目覚ましの際,照明がつき,Lineにメッセージが届くこと.\\
    \item 目覚ましの明かりの色によってその日の天気が分かること.\\
\end{itemize}
